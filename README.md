# 2048 game

A simple and engaging number puzzle where the player merges tiles with identical values to reach the **2048** combination.

The game develops logic, strategic thinking, and attentiveness, offering endless opportunities to sharpen your skills.


## Live Demo

Experience the live website: [2048 game](https://sertavr.github.io/2048_game/)

## Technologies Used

- **JavaScript (ES6+)**
- **Parcel**
- **ESLint**
- **eslint-plugin-node**
- **Prettier**
- **Stylelint**
- **stylelint-scss**


## Installation and Setup

 1. **Clone the repository:**
  ```bash
   git clone https://github.com/Sertavr/2048_game.git
  ```

 2. **Navigate to the project directory:**
  ```bash
   cd 2048_game
  ```

 3. **Install dependencies:**
  ```bash
   npm install
  ```

 4. **Start the local development server:**
  ```bash
   npm start
  ```
